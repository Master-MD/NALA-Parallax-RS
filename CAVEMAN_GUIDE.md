## 🇩🇪 DEUTSCH — CAVEMAN INSTALL & START
**Was macht das Ding?**
Es verbindet mehrere unterschiedliche Computer (Mac, Linux-PC mit NVIDIA/AMD/Intel-Grafikkarte, Mini-PC) zu **einem einzigen Riesen-Gehirn** für grosse KI-Modelle (`Qwen3-235B`, `DeepSeek-671B`) — in **100 % Rust-Turbo** (bis zu **542× schneller** als Python, **0 % Spionage-Telemetrie**).

### 1. In 1 Zeile installieren (Mac & Linux)
```bash
curl -fsSL https://github.com/Master-MD/NALA-Parallax-RS/releases/latest/download/install.sh -o install.sh && sh install.sh
```
*(Windows PowerShell: `irm https://github.com/Master-MD/NALA-Parallax-RS/releases/latest/download/install.ps1 | iex`)*

### 2. Die 3 wichtigsten Befehle
```bash
# 1) Verteilten Cluster-Plan auf Deutsch berechnen:
nala-parallax-rs --lang de --plan

# 2) Selbst-Test & Geschwindigkeits-Beweis (Rust vs. Python) starten:
nala-parallax-rs --bench

# 3) Interaktives 5-Sprachen Web-Cockpit öffnen (Port 18082):
nala-parallax-rs --lang de --serve --port 18082
```
